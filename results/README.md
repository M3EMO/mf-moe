# Salidas de las corridas B23 a B40

Cada carpeta guarda los JSON de una corrida del paper del olvido (`paper/forgetting/`).
El nombre de la carpeta es el id de la corrida y la placa usada (`gpu` o `cpu`).
Los JSON traen la configuración, la semilla y la pérdida por hecho de cada brazo.
Los checkpoints, los logs y las copias de los scripts quedan fuera del repo.
